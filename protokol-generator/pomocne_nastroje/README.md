# Pomocné nástroje

Sem patří pouze malé a opakovaně využitelné nástroje pro práci s DOCX, OMML, XLSX, schématy a kontrolním vykreslením.

Nevytvářet univerzální pevný generátor protokolů. Nástroje mají realizovat rozhodnutí AI pro konkrétní měření, nikoli nahrazovat individuální analýzu.

`vytvor_protokol_1z_zele.py` je historický nástroj použitý před ruční úpravou prvního protokolu. Není závazným generátorem ani zdrojem sazby. Pro další práci je zdrojem pravdy `vzory/vzor_vypoctovych_sekci.docx`; existující struktura a OMML objekty se mají klonovat z jeho pracovní kopie.
